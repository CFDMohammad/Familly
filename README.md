# Parallel 2D Lattice Boltzmann Solver for Lid-Driven Cavity Flow

## Description

This project implements a 2D Lattice Boltzmann Method (LBM) solver for simulating lid-driven cavity flow. The solver is parallelized using MPI (via `mpi4py`) to distribute the computational domain across multiple processes, allowing for larger simulations and faster execution times. The D2Q9 lattice model is used.

The simulation calculates the velocity field (u, v) within a square cavity where the top lid moves at a constant velocity. After the simulation, velocity profiles along the vertical and horizontal centerlines are extracted and saved.

A validation script is provided to compare these profiles against the well-established reference data from Ghia et al. (1982) for a Reynolds number of 1000.

## Dependencies

To run the simulations and validation scripts, you will need:

*   Python 3.x
*   NumPy: For numerical operations and array manipulation.
    ```bash
    pip install numpy
    ```
*   mpi4py: For MPI parallelization. Installation may vary depending on your system's MPI implementation (e.g., OpenMPI, MPICH).
    ```bash
    pip install mpi4py
    ```
*   Matplotlib: For generating validation plots (used by `plot_validation.py`).
    ```bash
    pip install matplotlib
    ```

You will also need an MPI implementation installed on your system (e.g., OpenMPI or MPICH) for `mpi4py` to function correctly.

## Running the Simulation

The parallel LBM simulation is executed using `lbm_mpi_cavity.py` with `mpirun` (or `mpiexec` depending on your MPI implementation).

```bash
mpirun -np <number_of_processes> python lbm_mpi_cavity.py
```

Replace `<number_of_processes>` with the desired number of MPI processes (e.g., 4).

### Configuration
Key simulation parameters can be configured at the top of `lbm_mpi_cavity.py`:
*   `Nx_global`, `Ny_global`: Global grid dimensions (e.g., `129` for a 128x128 cell domain).
*   `max_timesteps`: Total number of simulation time steps.
*   `u_lid`: Velocity of the moving top lid.
*   `tau`: LBM relaxation parameter. This is related to the kinematic viscosity (`nu`). The script is set up to calculate `nu` from `tau`. For validation (e.g., Re=1000), `tau` is typically calculated based on the target `Re`, `u_lid`, and grid resolution (e.g., `tau = 0.5384` for Re=1000, L=128, u_lid=0.1). The script currently contains values for Re=1000.

The simulation will print status updates to the console. Upon completion, rank 0 will save the velocity profiles (`u_profile_vertical_centerline.txt` and `v_profile_horizontal_centerline.txt`).

## Running the Validation

After running the LBM simulation and generating the velocity profile `.txt` files, you can run the validation script:

```bash
python plot_validation.py
```

This script will:
1.  Load the velocity profiles generated by `lbm_mpi_cavity.py`.
2.  Load the reference data from Ghia et al. (1982) for Re=1000 (embedded in the script).
3.  Generate and save two comparison plots:
    *   `u_velocity_validation_Re1000.png`: U-velocity along the vertical centerline.
    *   `v_velocity_validation_Re1000.png`: V-velocity along the horizontal centerline.

**Note:** `plot_validation.py` expects `u_profile_vertical_centerline.txt` and `v_profile_horizontal_centerline.txt` to be present in the same directory. The script also contains placeholder data generation for demonstration purposes if the LBM output files are missing, but for actual validation, these should come from a real simulation run.

## Output Files

### Velocity Profiles (`.txt`)
*   **`u_profile_vertical_centerline.txt`**:
    *   Contains two columns: normalized Y-coordinate (`y/L`) and U-velocity (`u/U_lid`) along the vertical centerline of the cavity (x=0.5).
*   **`v_profile_horizontal_centerline.txt`**:
    *   Contains two columns: normalized X-coordinate (`x/L`) and V-velocity (`v/U_lid`) along the horizontal centerline of the cavity (y=0.5).

These files are plain text and can be easily imported into other plotting or analysis tools.

### Validation Plots (`.png`)
*   **`u_velocity_validation_Re1000.png`**:
    *   A plot comparing the U-velocity profile from the LBM simulation with the Ghia et al. (1982) reference data at Re=1000.
*   **`v_velocity_validation_Re1000.png`**:
    *   A plot comparing the V-velocity profile from the LBM simulation with the Ghia et al. (1982) reference data at Re=1000.

These images provide a visual assessment of the simulation's accuracy.
